# Сверка — аудит отчёта Wildberries

Загрузите еженедельный отчёт-детализацию Wildberries (XLSX/CSV из WB Партнёры) —
**Сверка** пересобирает расчёт, находит спорные удержания (штрафы без основания,
дубли, завышенную логистику) и готовит текст претензии. **Всё считается в браузере:
файл никуда не загружается**, аккаунт и доступ к кабинету не нужны.

Один код → все платформы (PWA: телефон/десктоп/веб), офлайн после первого визита.

## Почему это не дефолт

WB отдаёт сырой нечитаемый отчёт и ручную форму спора — но никогда не говорит,
*какое* удержание неправильное. Платные SaaS требуют API-токен и работают на
сервере (ваши финансы наружу). Ров — **таблица правил** (`rules.js` → `RULESET`):
основания штрафов, признаки дублей, выбросы логистики, шаблоны претензий. Её надо
поддерживать под изменения WB — поэтому её не скопировать за ночь.

## Что делает v1

1. **Парсит** детализацию (`parse.js`) — распознаёт колонки по алиасам, устойчив к вариантам названий.
2. **Сверяет расчёт** по формуле WB: `К перечислению за товар − логистика − штрафы − хранение − приёмка − прочие + доплаты`.
3. **Ищет спорное** (`rules.js`): штрафы без основания · дубли удержаний по Srid · логистика выше медианы категории · отрицательная выплата по продаже · крупное хранение.
4. **Готовит претензию** — с номером отчёта, суммой, перечнем операций и куда подавать (срок ответа WB — 10 дней).

## Структура

| Файл | Роль |
|------|------|
| `parse.js` | Чистый парсер + P&L + сверка (юнит-тесты) |
| `rules.js` | Движок правил (ров) + генератор претензии |
| `sample.js` | Демо-отчёт для кнопки «Показать на примере» |
| `tests/` | 12 юнит-тестов, ноль зависимостей (`node --test`) |
| `app.js` | UI + чтение XLSX через SheetJS |
| `vendor/sheetjs/` | SheetJS, self-hosted (офлайн, приватность) |
| `sw.js` / `manifest.webmanifest` | PWA |
| `server.mjs` | Zero-dep статик-сервер для локали/хостинга |

## Запуск и тесты

```bash
node server.mjs   # http://localhost:4600
node --test       # 12/12
```

## Деплой (ноль затрат)

Любой статик-хостинг с HTTPS. GitHub Pages / Cloudflare Pages — free tier. Без бэкенда, без секретов, без стоимости эксплуатации.

## Монетизация (план)

Free — парсинг, сверка, счётчик находок, экспорт P&L. **Pro** (полные тексты
претензий, история недель, авто-сверка тарифов по габаритам, Ozon, экспорт в Excel)
через Boosty/Gumroad. ROI для селлера — возвращённые рубли.

## Ограничения / дальше

- Правила — **стартовый набор высоко-уверенных проверок**. Точная сверка логистики
  по габаритам требует актуальной тарифной таблицы WB (в Pro).
- Сверка недель (скачки хранения, медиана по SKU) — при загрузке нескольких отчётов (Pro).
- Тарифы/комиссии WB меняются среди года — правила надо держать в актуалье.
